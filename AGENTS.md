# GroupDocs.Metadata Docs — AGENTS.md

> Instructions for AI agents working with **GroupDocs.Metadata** documentation in this repository.

GroupDocs.Metadata is an on-premise SDK for reading, searching, editing, and removing metadata (EXIF, XMP, IPTC, Office properties, PDF info, ID3, and more) from **115+** document, image, audio, video, archive, font, CAD, and ebook formats.

**Supported formats (canon):** **115+** — see platform tables under each docs hub.
